# Online-Retail-Sales-Analysis
# Project  Overview
This project analyzes an online retail transaction dataset using python. The goal is to understand sales trends, top-performing
products, customer contribution and country-wise sales.
# Dataset 
The dataset contains 500k+ retail transaction record with information such as:
- invoice number
- product code
- product description
- quantity
- invoice date
- unit price
- customer Id
- country
# language use:
python, pandas, NumPy, Matplotlib and Seaborn, Jupyter notebook
# Project Workflow
1. Data Loading
2. Data undersatnding
3. Data Cleaning
4. Feature preparation
5. Sales Analysis
6. Product Analysis
7. Customer Analysis
8. Country-wise Analysis
9. Data Visualization
10. Business Insights

# Analysis
The project analyzes:
- Monthly sales trends
- Top products by total sales
- Top products by quantity sold
- Average product prices
- Top customer by sales
- Country-wise sales

# Conclusion
The analysis provided insights into product performance, customer contribution, sales trends and country-wise business performance.
